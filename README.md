## ⚡ Flagship Architectures & Research

### 1. 📓 **Cognitive Mirror & Diary Analytics** — [`personal-metric`](https://github.com/shatinz/personal-metric)
> *Bridging qualitative introspection with quantitative telemetry.*
* **Architecture**: Automated pipeline syncing qualitative journal narratives with screen-time telemetry (ActivityWatch).
* **NLP Pipeline**: Grammatical POS ratios, DistilRoBERTa emotion profiling, lexical creativity metrics, and dynamic vector clustering.
* **Stack**: `Python` • `Streamlit` • `SentenceTransformers` • `DistilRoBERTa` • `VADER` • `PyInstaller`

### 2. 🤖 **Autonomous AI Lead Generation & Agent Gateways** — [`telegram-agent`](https://github.com/shatinz/telegram-agent) & [`security-sentinel`](https://github.com/shatinz/security-sentinel)
> *Autonomous multi-provider agent loops with security guardrails.*
* **Architecture**: Autonomous agent monitoring 500+ real-time channels & marketplace feeds, evaluating lead compatibility via multi-LLM fallback chains (`Google GenAI` → `Cloudflare Workers AI`), generating custom proposals, and executing pre-push AI security gates.
* **Stack**: `Python` • `LangGraph` • `Telethon` • `Playwright` • `Google GenAI` • `PowerShell`

### 3. 🔬 **DMT Trip Reports — Computational NLP Pipeline** — [`tripreports`](https://github.com/shatinz/tripreports)
> *Empirical semantic modeling and statistical validation on psychedelic narratives.*
* **Architecture**: End-to-end ML research pipeline analyzing 1,100+ unstructured experience narratives using semantic embeddings, UMAP dimensionality reduction, and HDBSCAN clustering.
* **Validation**: Spearman correlation matrices with p-values and 1,000-iteration bootstrap confidence intervals; automated publication-ready paper generation.
* **Stack**: `Python` • `SentenceTransformers` • `UMAP` • `HDBSCAN` • `Scikit-learn` • `Pandas`

### 4. 🌲 **Berim Gear Hub & High-Performance Web Platforms** — [`berim-gear-hub`](https://github.com/shatinz/berim-gear-hub)
> *E-commerce infrastructure with 3D interactions and automated data ingestion.*
* **Architecture**: Modern outdoor gear commerce hub featuring 3D interactive visualizations, automated product catalog scrapers routed through SOCKS5 proxy failovers, and integrated Telegram commerce bots.
* **Stack**: `Next.js` • `TypeScript` • `Tailwind CSS` • `Express` • `Linux Systemd`
